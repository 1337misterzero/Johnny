The idea behind this firmware is to turn the Cardputer Adv into a small, self-contained operating system capable of handling SD card media such as audio, images, and video.

Built on top of that is a collection of information security tools, including Wi-Fi phishing, Bluetooth spam, beacon attacks, and controlled malware experiments involving Trojans, worms, and ransomware.

The whole thing is wrapped in a *Cyberpunk 2077™* inspired Johnny Silverhand theme, with extras like a guitar tuner and MIDI support with distortion effects.

It may sound impractical—and honestly, it is. There are already plenty of ESP32 projects like this; the real challenge is getting everything working on the Cardputer Adv's hardware.

It's useless, unnecessarily complicated, and that's exactly why I want to build it.
